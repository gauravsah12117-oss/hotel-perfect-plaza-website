    Fingerprint machines

    How to connect the machine
    1. Connect the machine to the hotel's internet: a LAN cable to the router. On the machine: Menu → Comm. → Ethernet → DHCP: ON.
    2. On the machine: Menu → Comm. → Cloud Server Setting (on some models: ADMS).
    3. Enable Domain Name: ON, server address www.hotelperfectplaza.com (with the www).
    4. Server port: 443, HTTPS: ON, Proxy: OFF. Save and restart the machine.
    5. Within a minute it appears in the table above. Check the serial number (Menu → System Info → Device Info) and press Approve. Every punch arrives from then on, including the ones it stored before.
    6. Check the machine's date and time (Menu → System → Date Time). Every time shown comes from the machine's clock.

    The hotel's rules, and what gets notified

    "Late after 10" means 9:10 is on time and 9:11 is 11 minutes late. "Overtime from 30" means staying 20 minutes extra isn't overtime, and 45 minutes is.

    Backup

    A copy of every record on this device: the staff, their leave, the holidays, the settings and a year's punches. Download one every few months and keep it safe (email it to yourself, or a pen drive).
