    Fingerprint machines

    How to connect the machine: Hikvision
    1. Connect the terminal to the hotel's internet: a LAN cable to the router (or its Wi-Fi, on Wi-Fi models).
    2. On a computer on the hotel's network, open the terminal's IP address in a browser (shown on the terminal under Communication → Network) and sign in as admin. Or in iVMS-4200: Device Management → the terminal → Remote Configuration.
    3. Go to Configuration → Network → Network Service → HTTP Listening (on some firmware: Event Alarm or Alarm Server).
    4. Event alarm IP address / domain name: www.hotelperfectplaza.com · URL: /api/hik · Port: 443 · Protocol: HTTPS. Save. MeroHajir's own connection can stay until you stop using it.
    5. Put a finger on the terminal. Within a minute it appears in the table above as HIK- and its MAC address. Press Approve, then punch once more: punches only count from approval.
    6. Each person's Employee No. on the terminal is their Machine no. in Staff.
    7. Time: Configuration → System → Time Settings: time zone (GMT+05:45) Kathmandu, NTP on.
    How to connect the machine: ZKTeco or eSSL
    1. Connect the machine to the hotel's internet: a LAN cable to the router. On the machine: Menu → Comm. → Ethernet → DHCP: ON.
    2. On the machine: Menu → Comm. → Cloud Server Setting (on some models: ADMS).
    3. Enable Domain Name: ON, server address www.hotelperfectplaza.com (with the www).
    4. Server port: 443, HTTPS: ON, Proxy: OFF. Save and restart the machine.
    5. Within a minute it appears in the table above. Check the serial number (Menu → System Info → Device Info) and press Approve. Every punch arrives from then on, including the ones it stored before.
    6. Check the machine's date and time (Menu → System → Date Time). Every time shown comes from the machine's clock.

    The hotel's rules, and what gets notified

    No punch notifications during quiet hours (for example 22:00 to 06:00): the punches are still recorded, and the 9 pm summary still comes. Leave both empty for none.

    Shifts for the roster

    "Late after 10" means 9:10 is on time and 9:11 is 11 minutes late. "Overtime from 60" means staying 30 minutes extra isn't overtime, and an hour is.

    Backup

    A copy of every record on this device: the staff, their leave, the holidays, the settings and a year's punches. Download one every few months and keep it safe (email it to yourself, or a pen drive).
