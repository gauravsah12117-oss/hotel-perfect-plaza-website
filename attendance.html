    Totals and pay

    Pay = monthly salary − unpaid days × day rate (salary ÷ 30) + overtime pay. Absent, unpaid leave, half a day for a half day, and days before someone joined are unpaid. Days still to come aren't counted. Tap a name to see every day.

    The app on a phone

    This is the app. It's on this phone's home screen, and opens signed in.

    Put this page on the home screen of your phone, or your father's, as an app called हाजिरी. It opens full screen and stays signed in. Open on that phone, sign in, then:

    • Android: press Install app at the top of the page. If it isn't there: Chrome's ⋮ menu → Add to Home screen → Install.
    • iPhone: in Safari, press Share (the square with the arrow) → Add to Home Screen → Add.

    With Telegram on the same phone, he gets the arrival messages there, and opens the app for the full day or the month.

    Notifications on this phone

    The app pops up a notification the moment someone puts their finger on the machine: who, what time, and if they're late. Free, and nothing else to install. Turn it on once on each phone that should get them.

    "Late after 10" means 9:10 is on time and 9:11 is 11 minutes late. "Overtime from 30" means staying 20 minutes extra isn't overtime, and 45 minutes is.

    How to connect the machine
    1. Connect the machine to the hotel's internet: a LAN cable to the router, or Wi-Fi if the model has it (Menu → Comm → Ethernet / Wireless).
    2. On the machine: Menu → Comm. → Cloud Server Setting (on some models: ADMS).
    3. Turn on Enable Domain Name and type the server address:
    4. Turn on HTTPS if the machine has that option, and set the port to 443. If it has no HTTPS option, see "Machine without HTTPS" in ATTENDANCE.md.
    5. Leave Proxy server off. Save and restart the machine.
    6. Within a minute it appears in the table above. Press Approve, and every punch arrives from then on, including the ones it stored before.
    7. Check the machine's date and time are right (Menu → System → Date Time). Messages use the machine's clock.
